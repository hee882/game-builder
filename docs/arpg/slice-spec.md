# 연무 — 오프라인 파밍 절편 설계 (현행 기준 문서)

기준일 2026-11-07. 이 문서가 현재 방향의 단일 기준이다. 이전 콤보 액션 방향 문서는 [보관 안내](#보관된-이전-방향)를 따른다.
수치는 모두 **가설**이며 플레이와 계측으로 조정한다.

## 1. 사용자 결정 (승인됨, 2026-11-07)

| 항목 | 결정 |
|---|---|
| 장르 | 쿼터뷰 핵앤슬래시 액션 RPG. 빠른 템포, 몹 무리 쓸어버리기, 화려한 스킬, 쉬운 빌드 교체 |
| 금지 | 특정 기존 게임의 이름·캐릭터·아트·레벨·아이템명 복제. 장르 문법만 사용 |
| 세계관 | 조선풍 가상 퇴마 판타지 유지 |
| 조작 | 좌클릭 이동·공격(적 클릭 시 추적 공격), 우클릭 + 1~4 스킬 슬롯 |
| 첫 목표 | 혼자 하는 오프라인 파밍 한 바퀴. 서버·온라인·퀘스트 체인 제외 |
| 직업 | 환도 퇴마사 1종 (근접 + 광역 + 이동기) |
| 시각 | 던전·몹은 임시 도형. 주인공만 이후 힉스필드 모델로 교체(모델 교체 가능한 구조) |
| 한 판 | 10~15분. 장비·레벨은 브라우저 로컬 저장, 재진입 시 던전은 새 시드 |
| 작업 체계 | 구현은 Codex Astra 또는 사용량 부족 시 Claude, 점검은 Claude |

## 2. 핵심 루프

```text
마을 문 → 던전 진입(새 시드) → 몹 무리 정리 → 정예 무리 → 보스 → 보상 상자
   ↑                                                         │
   └──── 장착·스킬 교체 ← 레벨업·드랍 획득 ←──────────────────┘
```

재미 목표: ① 스킬 한 번에 몹 여러 마리가 동시에 쓰러지는 쾌감 ② 드랍 빛기둥을 보고 달려가는 기대 ③ 새 장비·전설 효과로 스킬 쓰는 방식이 바뀌는 순간.

## 3. 조작

| 입력 | 동작 |
|---|---|
| 좌클릭(땅) / 누른 채 끌기 | 해당 지점으로 이동(타일 길찾기) |
| 좌클릭(적) | 사거리까지 추적 후 기본 공격 반복 |
| 좌클릭(아이템) | 걸어가서 줍기 |
| 우클릭, 1~4 | 슬롯 스킬을 커서 지점/방향으로 사용 |
| I / K | 인벤토리 / 스킬 창 |
| Shift + 좌클릭 | 제자리 공격 |

## 4. 환도 퇴마사

자원 **기(氣)** 0~100. 기본 공격으로 채우고 스킬로 쓴다.

| ID | 이름 | 해금 | 비용·쿨다운 | 효과 |
|---|---|---|---|---|
| `slash` | 베기 | 1 | 기 +8 | 전방 부채꼴 근접, 무기 피해 100% |
| `spin` | 회전베기 | 1 | 기 25 | 주변 원형, 160% |
| `dash` | 질풍 돌진 | 2 | 쿨 4초 | 커서 방향 최대 6m 돌진, 경로 적 120% |
| `talisman` | 폭염 부적 | 3 | 기 30 | 커서 지점 반경 3m 폭발, 220% |
| `cleave` | 혼백 가르기 | 5 | 쿨 6초 | 전방 넓은 원뿔, 400%, 강한 경직 |
| `ward` | 금줄 결계 | 7 | 쿨 15초 | 5초간 주변 적 둔화 40%, 받는 피해 -30% |

슬롯: 좌클릭은 `slash` 고정. 우클릭·1~4는 해금된 스킬 중 아무거나 배치(스킬 창에서 교체, 전투 중에도 가능).

## 5. 장비

슬롯 6: 무기(환도), 갓, 도포, 토시, 신, 노리개.

| 희귀도 | 색 | 랜덤 옵션 수 |
|---|---|---|
| 일반 | 흰 | 0 |
| 마법 | 파랑 | 1~2 |
| 희귀 | 노랑 | 3~4 |
| 전설 | 주황 | 3 + 전설 효과 1 |

옵션 풀: 공격력 %, 체력 +, 공격 속도 %, 치명타 확률 %, 치명타 피해 %, 이동 속도 %, 기 재생, 처치 시 체력 회복, 특정 스킬 피해 %, 쿨다운 감소 %.

전설 효과(첫 절편 3종, 스킬 동작을 바꾼다):

| 이름 | 슬롯 | 효과 |
|---|---|---|
| 불길 걷는 환도 | 무기 | 질풍 돌진 경로에 3초간 불길(초당 60%) |
| 메아리 노리개 | 노리개 | 회전베기가 0.4초 뒤 한 번 더 회전 |
| 귀화 부적 토시 | 토시 | 폭염 부적이 작은 부적 3개로 갈라져 주변에 추가 폭발 |

드랍(가설): 일반 몹 아이템 8% · 체력 구슬 15%, 정예 아이템 1~2개, 보스 3개(희귀 이상 1개 보장). 전설 확률 일반 1% · 정예 5% · 보스 25%. 아이템 레벨 = 던전 레벨.
인벤토리 30칸. 비교 툴팁은 착용 중 장비와 차이를 초록/빨강으로 표시.

## 6. 성장

- 레벨 상한 10(절편). 다음 레벨 필요 경험치 `round(100 × L^1.5)`.
- 몹 경험치 `10 × 던전 레벨`, 정예 ×5, 보스 ×30.
- 기본 체력 140, 레벨당 체력 +10, 기본 피해 +8%. 스킬 해금은 §4.
- 던전 레벨 = 진입 시 플레이어 레벨.

## 7. 던전

- 타일 격자(1타일 = 1m = 1000 단위). 시드로 방 6~9개 생성, 복도로 연결, 모든 방이 시작 방에서 도달 가능.
- 방 종류: 시작, 일반(몹 무리 6~15마리), 정예(정예 1 + 하수인 4~6), 보스(가장 먼 방).
- 보스 처치 후 보상 상자와 마을 문(재진입) 생성.
- 목표 한 판 10~15분. 몹 총수 100~160마리(가설).

## 8. 적

| ID | 이름 | 역할 |
|---|---|---|
| `reed` | 억새 잔향 | 떼 근접, 체력 낮음, 빠름 |
| `shield` | 방패 역졸 | 정면 피해 50% 감소, 느림 |
| `porter` | 그림자 등짐장수 | 원거리 투척, 거리 유지 |
| `hat` | 되돌이 삿갓 (보스) | 예고 후 원형 휩쓸기, 억새 소환, 체력 50% 이하 분노 |

정예 접두어(1개): 날쌘(이속 +40%), 단단한(체력 ×2), 분열하는(죽을 때 억새 3마리). 정예는 이름표 표시.
위험 공격은 바닥 예고(텔레그래프) 후 발동. 잡몹 일반 공격은 짧은 예고만.

## 9. 기술 계약

- `packages/sim`: 순수 TS, 30Hz 고정 스텝, 결정적(시드 RNG를 상태에 보관). three.js·DOM 금지.
- `apps/client`: three.js 렌더·입력·UI·오디오·저장. sim 상태를 읽어 보간 렌더.
- 길찾기: 플레이어 클릭 시 타일 A*(8방향). 적은 직선 추적 + 분리력, 막히면 타일 흐름장.
- 군중 처리: 공간 해시(셀 2m)로 근접·충돌·광역 판정. 적 메시는 종류별 InstancedMesh. 이름표는 정예·보스만. 효과 풀 상한 64, 동시 발음 상한 8.
- 히트스톱(군중 규칙): 전역 정지는 치명타·대형 스킬에만 최대 2틱, 겹쳐도 합산하지 않음. 일반 타격은 적 개별 번쩍임·밀림으로 표현.
- 저장: `localStorage['yeonmu.save.v1']` = `{version, level, xp, inventory, equipped, slots, runCount}`. 읽기 실패·버전 불일치 시 백업 키에 원본을 남기고 새로 시작.

## 11. 측정 전 / 미검증

재미, 한 판 길이, 드랍률 체감, 목표 PC 성능, 힉스필드 모델 품질과 리깅 호환은 모두 미측정이다.

## 보관된 이전 방향

`docs/design/*`, `docs/technical/*`, `docs/production/*`의 기존 문서는 "보상 없이 재미있는 키보드 분기 콤보 + 온라인" 방향의 기록이다. 세계관(`narrative.md`)과 일부 기술 원칙(sim/client 분리, 결정성)은 계속 참고하지만, 범위·전투·아이템·단계 계획은 이 문서가 우선한다. 단계 0 구현(`impl/p0-combat-proof`)은 이력으로 보존한다.
