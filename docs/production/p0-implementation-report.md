## 시간과 판정 계약

- `state.tick`은 세계 시계, `player.actionTick`은 히트스톱에 정지하는 단조 로컬 시계다. 동작의 상대 시간은 `actionTick - action.start`다. 모든 창은 반열림 구간이다.
- 약공 판정 `[3,5)`, 끝 13; L1 일반 연결 `[5,12)`, 지연 `[12,21)`, 21부터 새 L1. L4 끝 17, 회피 캔슬 9. H 판정 `[8,10)`, H 연결 15, 회피 14. 일섬은 18틱 차지 후 판정 `[3,6)`, 끝 20.
- 입력 버퍼 5틱. 튕겨내기 `[0,5)`가 누른 틱부터 즉시 적용된다. 성공 시 4틱 정지 후 15틱 반격. 홀드는 5틱 뒤 막기로 전환, 탭 실패는 10틱 후딜이다.
- 회피 무적 `[1,7)`, 완벽 회피 `[1,4)`, 동작 13틱, 이후 5틱 반격. 3연속 회피 뒤 12틱 지침은 공격으로 생략하지 못한다.
- 한 타격 다중 대상 정지는 최대값 1회. 동일 타격·동일 대상은 정지 중 재적중하지 않는다. 삼연 찌르기는 3개 독립 판정이다.
- 적 예고는 세계 틱으로 진행한다. 일반 적 피격 경직은 명시적으로 공격을 중단하며, 플레이어 히트스톱과 구분한다. 보스는 일반 피격으로 멈추지 않고 되받아 베기에만 짧은 그로기를 받는다.
- 문서에 개별 타이밍이 없는 올려베기·삼연 찌르기·지연·반격 노드의 세부 틱과 모든 피해·사거리·HP는 **구현 초깃값**이다. 기존 설계의 확정값이나 재미 측정값으로 간주하지 않는다.
- 소프트 록온과 충돌은 8방향 정수 근사다. 정식 연속 각도 ±30° 콤보 조준 보정·정교한 무기 스윕은 미구현이다.

## 자동 검증

환경: Windows, Node.js `v24.11.0`, npm `11.19.1`. 고정 의존성: three `0.180.0`, @types/three `0.180.0`, TypeScript `5.9.3`, Vite `7.3.7`, Vitest `5.1.0`.

최종 실행 원문은 저장소의 무시된 로컬 파일 `artifacts/verification.txt`에 있다. 순서는 `npm ci` → `npm run check` → `npm test -- --reporter=verbose` → `npm run build`이며 각 명령이 실패하면 다음 명령을 실행하지 않도록 검사했다. verbose는 요청된 `npm test`의 출력 옵션만 추가한 것이다.

- `npm ci`: 45개 패키지 설치, 48개 감사, 취약점 0건(12초). npm의 esbuild postinstall 승인 목록 경고가 있었으나 종료 코드는 0이며 뒤의 빌드도 성공했다. 사용자 전역 설정은 변경하지 않았다.
- `npm run check`: 루트 TS 검사, DOM 라이브러리 없이 sim만 별도 TS 검사, 경계 검사, 콘텐츠 테스트 4개 통과.
- `npm test`: 2개 파일 / 26개 테스트 통과, skip/삭제 없음.
- `npm run build`: check 재실행 후 Vite 프로덕션 빌드 통과(22모듈, 2.49초). HTML 0.37kB, CSS 4.98kB, JS 521.00kB(gzip 136.32kB). three.js 포함 단일 JS 청크가 500kB를 넘어 경고가 발생한다. 경고를 숨기지 않았다. 빌드 산출물은 Git 제외.
- 최초 Vitest 기본 탐색이 `vendor`의 Node 내장 테스트까지 주워 실패한 적이 있다. 테스트 include를 이 저장소의 `packages/**/test`와 `apps/**/test`로 한정하여 격리했으며 vendor 파일은 변경하지 않았다.
