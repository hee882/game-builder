## 중단 지점

두 작업자의 완료 보고 수령 후 동일 작업자에게 교차 검토·수정을 재위임하려 했으나 PowerShell에서 다음 오류가 발생했다.

> orca : 'orca' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다.

Orca 스킬의 실행 파일 실패 시 중단 지침에 따라 대체 실행 파일이나 비-Orca 작업자로 우회하지 않았다. 후속 교차 검토 Dispatch는 생성됐다고 확인할 수 없다. 완료 Delivery `delivery_3eaff36e83f6`의 ack 명령도 같은 오류로 실패했다. 기존 두 작업자는 성공 정산됐지만 release/reuse가 완료되지 않았다. 사용자 요청에 의한 retain 상태가 아니다.

## 재개할 일

1. 동일 Orca 실행 환경이 복구되면 Run과 Delivery를 재확인한다. 기존 완료 작업을 중복 실행하지 않는다.
2. 각 기존 작업자를 재사용해 상대 문서를 교차 검토하고, 각자 소유한 문서만 수정한다.
3. 특히 패링 시간(30Hz 최소 5틱), 재접속 보호 3초, 보스 기여도와 인원 스케일링, 포탈·퀘스트 보상, 콤보 노드별 애니메이션 예산을 대조한다.
4. 별도 Claude 작업자로 독립 검증 후 필요한 수정 작업을 위임한다.
5. 완료된 작업자 자원을 release하고 미정리 자원이 없는지 확인한다.

현재 문서는 **설계 초안**이며 교차 검토·독립 검증 완료본이 아니다. 게임 구현·성능 측정·배포·원격 게시를 수행하지 않았다.
