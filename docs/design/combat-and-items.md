## 2. 입력 체계 <a id="input"></a>

### 2.1 기본 키 배치 (키보드 + 마우스) [제안]

| 동작 | 기본 키 | 키보드 전용 모드 | 비고 |
|------|---------|------------------|------|
| 이동 | W A S D | W A S D | 카메라 기준 8방향 |
| 공격 방향 | 마우스 커서 | 이동 방향 + **소프트 록온**(전방 90° 내 가장 가까운 적) | 공격 시작 순간 방향 고정, 이후 콤보 중 ±30° 보정 |
| 약공 (L) | 마우스 좌 | J | |
| 강공 (H) | 마우스 우 (홀드 = 차지) | K | |
| 회피 | Space | L | 이동 입력 방향, 없으면 커서 반대 방향 |
| 튕겨내기 / 막기 | Shift (탭 = 튕겨내기, 홀드 = 막기) | ; | 홀드↔토글 옵션 |
| 기술 1~4 | Q E R F | U I O P | 쿨다운형 |
| 잔향 해방 | Tab | H | 기세 3칸 소모 |
| 응답·상호작용 | G | G | 보스 '이름 부르기' 응답, 레버 등 |
| 소모품 | 1 2 3 4 | 1 2 3 4 | |
| 귀로등 | T | T | 시전 3초, 피격 시 취소 ([Q-M02 규칙](quests.md#q-m02)) |
| 채팅 / 감정표현 | Enter / B | Enter / B | 전투 중 감정표현 비활성 |

- **모든 키 재지정 가능.** 컨트롤러는 첫 절편 범위 밖이지만, 콤보 정의가 "L/H + 박자 + 상태"뿐이라 이식 가능.
- 쿼터뷰에서 **방향키 + 공격** 조합 분기(예: 뒤+약공)는 쓰지 않는다. 카메라 기준 방향과 캐릭터 기준 방향이 헷갈리기 때문. [제안, 가정 A2]

## 3. 타이밍 제안 <a id="timing"></a>

기준 60fps (1f ≈ 16.7ms). 모든 값 [제안].

### 3.1 공통

| 항목 | 값 | 의도 |
|------|----|------|
| 입력 버퍼 | **9f (150ms)** | 너무 이른 입력도 다음 동작으로 연결 |
| 박자 분기 창 | 이전 공격 판정 종료 후 **15~30f (250~500ms)** 에 다음 약공 = 지연 분기. 0~15f = 일반 연결. 30f 초과 = 콤보 리셋 | 리듬으로 분기를 고르는 감각 |
| 박자 신호 | 지연 창이 열리는 순간 칼끝 반짝임 + 짧은 쇳소리 (옵션으로 화면 아이콘) | 가독성·접근성 |
| 히트스톱 | 약공 3f · 강공 6f · 튕겨내기 8f · 보스 마무리 12f | **공격자·피격자 화면 로컬 연출**, 판정에는 영향 없음 |
| 피격 경직 (일반 적) | 약공 12f · 강공 24f | |

|------|------|------|------|-------------------|-------------|
| 약공 L1~L3 | 7f | 3f | 16f | 판정 종료 직후부터 | 판정 종료 직후부터 |
| 약공 L4 (마무리) | 9f | 4f | 22f | 불가 (콤보 끝) | 후딜 6f 이후 |
| 강공 H | 16f | 4f | 24f | 후딜 10f 이후 H만 | 후딜 8f 이후 |

| 회피 | — | 무적 2~13f (200ms) | 총 26f | 회피 후 10f 안에 L = 흘려베기 | 연속 3회 후 지침 24f |

### 3.3 텔레그래프 최소 리드타임 (적 → 플레이어)

| 적 공격 등급 | 예고 시작 → 판정까지 최소 |
|--------------|--------------------------|
| 일반 적 약공 | 400ms |
| 일반 적 강공·잡기 | 600ms |
| 보스 단일 대상 | 600ms |
| 보스 광역 (빨강) | 800ms |
| 보스 '이름 부르기' | 4,000ms (대상 지정 후) |

**즉사 공격 없음** — 절편의 어떤 단일 공격도 기본 방어구 기준 최대 체력의 60%를 넘지 않는다. [제안]

### 3.4 온라인 요구사항 (technical에 요청)

- 내 입력의 **반응(애니메이션 시작)은 로컬에서 즉시** 보여야 한다. 목표: 입력 → 첫 프레임 표시 ≤ 50ms (로컬). [가정, 측정 필요]
- 튕겨내기·완벽 회피 판정은 **방어자에게 유리하게**(플레이어 화면에서 성공이면 성공으로 인정하는 허용 폭) 처리되기를 희망. 허용 폭·악용 방지는 technical 결정. ([concept A3](concept.md#assumptions))
- **히트스톱 동안 콤보 창·박자 창은 흐르지 않는다.** 디자인 의도는 "히트스톱이 길어도 박자 분기가 같은 손감각으로 나간다"이며, 이는 [architecture.md §9](../technical/architecture.md)의 `actionTick` 정지 모델(공격자 동작 타임라인만 정지)과 일치한다. 이 문서의 ms·프레임 값은 **디자인 의도값**이고 구현은 `actionTick` 단위로 환산한다.
- 서버 30Hz 틱(≈33ms)에서는 튕겨내기 150ms ≈ 4.5틱. 환산 시 **튕겨내기 창은 최소 5틱**, 박자 분기 창 경계는 반올림이 아닌 플레이어 유리 방향으로 처리하기를 요청.
- **화면 전체 정지형 히트스톱은 쓰지 않는다**(1인 인스턴스 포함). 히트스톱은 공격자·피격 엔티티 표현에만 적용 — architecture §9.3의 열린 질문에 대한 디자인 답.
- 고지연 시 튕겨내기 창 **자동 확대는 하지 않는다**(architecture §10과 합의). §5.2의 '튕겨내기 창 +50%'는 플레이어가 직접 켜는 접근성 옵션이며, PvE 전용이므로 허용한다. [제안]

### 4.4 잔향 해방 (Tab)

기세 3칸을 소모해 **장착 잔향구 고유의 해방기**를 쓴다. 잔향구가 없으면 환도 기본 해방기 `연무참`(전방 3연 돌진 베기). 각 잔향구 해방기는 [§7](#legendaries).

## 5. 가독성과 접근성

### 5.1 가독성 — "화려하지만 읽히는" [요구 → 제안]

| 규칙 | 내용 |
|------|------|
| **3중 부호화** | 적 공격 예고는 **색 + 무늬 + 소리** 셋으로 동시에 알린다. 색만으로 구분하지 않는다. |
| 빨강 | ✕ 빗금 무늬 · 낮은 징 소리 → **막기·튕겨내기 불가, 회피** |
| 노랑 | ◇ 테두리 섬광 · 방울 소리 → **튕겨내기 가능** |
| 보라 | 물결 무늬 장판 · 낮게 깔리는 곡소리 → **머물면 피해, 이동** |
| 흰 깜빡임 | 손 모양 무늬 · 천 찢는 소리 → **잡기, 회피 또는 기합** |
| 렌더 우선순위 | 적 예고 > 내 캐릭터 > 적 > 파티원 효과 > 내 효과 장식 |
| 파티원 효과 | 기본 불투명도 50% (옵션 0~100%) |
| 내 효과 | 화려하게. 단 적 예고 영역과 겹치면 자동으로 30%까지 투명화 |
| 피해 숫자 | 기본 '중요만'(치명·가드 브레이크·관통). 전체/끔 선택 |
| 가림 | 벽·지붕 뒤 캐릭터와 적은 실루엣 표시 (쿼터뷰 필수) |
| 사망 원인 | 사망 화면에 마지막 피격 공격 이름 + 예고 색 표시 ([G4](concept.md#gates)) |

### 5.2 접근성 옵션 [제안]

| 범주 | 옵션 |
|------|------|
| 입력 | 전체 키 재지정, 홀드↔토글(막기·차지), 키보드 전용 모드 |
| 타이밍 보조 | 튕겨내기 창 +50%(150→225ms), 박자 분기 창 확장(250~700ms), 입력 버퍼 150→250ms |
| 콤보 보조 | **원버튼 콤보 모드** — 약공 연타만으로 상황에 맞는 분기(지연 베기 등)가 자동으로 섞임. 보상·기록 차별 없음 |
| 시각 | 텔레그래프 대비 강화, 색각 보정 팔레트 3종, UI·글자 크기, 화면 흔들림·히트스톱·섬광 슬라이더, 광과민 모드 |
| 청각 | 자막, **소리 방향 시각화**(예고 소리를 화면 가장자리 아이콘으로) |
| 연습 | 1인 수련장에서만 '느린 장단'(게임 속도 70%) — 온라인 인스턴스에서는 속도 조절 불가 |

목표: 보조 옵션을 켠 비숙련 테스터 완주율 ≥ 90% ([G8](concept.md#gates)).

## 7. 잔향구 — 동작을 바꾸는 전설 6종 <a id="legendaries"></a>

**규칙** [제안]

- 잔향구는 **같은 등급 일반 장비와 기본 수치가 같다.** 차이는 동작뿐.
- 각 잔향구는 **1절**(기본 동작 변화)과 **2절**(T4 승화, 도전 과제로 해금)을 가진다.
- 모든 잔향구에는 **대가**가 있다 — 무언가를 얻으면 무언가를 잃는다. 그래서 장착은 "업그레이드"가 아니라 "스타일 선택".
- 동시 장착: 첫 절편 1개, 출시 2개. 같은 노드를 두 잔향구가 바꾸면 **무기 > 장신구 > 방어구** 우선이며, 장착 전 UI에 충돌을 표시한다.
- 마을에서 **외형으로 드러난다** — 낯선 길손이 무엇을 쓰는지 보이는 것 자체가 사회적 동기.
- 출처 보스와 세계 규칙: 물건에 깃든 잔향이 생전 몸놀림을 물려준다 ([narrative W4](narrative.md)).

## 8. 제작과 레시피 진행 <a id="crafting"></a>

### 8.1 장비 슬롯과 등급

- 슬롯: **무기 · 머리 · 몸 · 손목 · 신발 · 장신구**
- 등급: **일반(T0) → 장인(T1) → 잔향구(T3)**. T2는 등급이 아니라 개조(각인), T4는 잔향구 승화.

### 8.2 장인 등급 (강막쇠 신뢰도)

| 단계 | 해금 | 할 수 있는 것 | 재료 예 | 범위 |
|------|------|--------------|---------|------|
| **T0 기본** | 시작 | 상점 장비 | — | 절편 |
| **T1 장인** | [Q-S01](quests.md#q-s01) | 환도·방어구 T1 제작 (+10% 위력·방어, 유일한 수치 상승) | 녹슨 철편, 무명천 | 절편 |
| **T2 개조(버릇 각인)** | [Q-S02](quests.md#q-s02) | 콤보 노드 1개에 **작은 동작 변형** — 수치 없음. 마을에서 무료로 교체 가능 | 억새 줄기, 잔향 조각 | 절편 |
| **T3 잔향구** | [Q-M05](quests.md#q-m05) | 잔향구 제작 | 보스 기억 + 공명석 + 지역 재료 | 절편 |
| **T4 승화** | [Q-S06](quests.md#later-variants) | 잔향구 2절 | 도전 과제 달성 증표 + 이름패 조각 | 1막 출시 |

**T2 버릇 각인 예시:** `마무리 횡베기 → 2연 베기로` / `일섬 차지 0.6초 → 0.45초, 돌진 거리 −30%` / `흘려베기 → 뒤로 빠지며 베기` / `회전 베기 → 끌어당기는 회전`. 각 각인은 §1의 C5 원칙대로 **동작을 바꾸되 위력을 올리지 않는다.**

| 무명천 | 억새 잔향·곡소리꾼 드랍, 상점 | 귀속 | T1, 잔향구 |
| 억새 줄기 | 억새벌 채집 | 귀속 | T2, 잔향구 |
| 잔향 조각 | 모든 잔향 적 (일반 드랍) | 귀속 | T2 각인 |
| **공명석** | 중간보스·보스 **첫 처치 확정 1개**, 주간 변이 첫 클리어 1개 | 귀속 | 잔향구 |
| **보스 기억** | 보스 **첫 처치 확정**. 재처치 시 '기억 결' 1개(3개 = 기억 1개, 확률 없음) | 귀속 | 잔향구 |
| 울음의 재 | [Q-M05](quests.md#q-m05) '풀어 준다' 선택 | 귀속 | 곡비 기억 대체재 |
| 이름패 조각 | 조사 퀘스트(가온) | 귀속 | 잔향구(1막 이후), 승화 |
| 동행 공적 | 도우미 보상 ([quests §2.2](quests.md#party-rules)) | 귀속 | 공명석·재료 교환 |

> 거래소가 없으므로 첫 절편 재료는 **모두 귀속**. 거래 도입 여부는 [concept §9](concept.md#scope-out)대로 별도 결정.

### 8.4 레시피 발견

- 잔향구 레시피는 **해당 보스와 처음 마주친 순간 공개**된다(져도 공개). 목표가 보이면 다시 도전할 이유가 생긴다.
- 레시피북에는 실루엣 + "어디서 기억을 찾을 수 있는가" 힌트를 표시.
- 가온의 문서, 막쇠의 신뢰 대사로 T2 각인 레시피가 열린다 — **발견이 새 행동을 연다.**

### 8.5 실험 비용을 낮춘다

- 잔향구 **해체 시 기억·공명석 전액 반환**(지역 재료만 소모). T2 각인은 마을에서 무료 교체.
- 이유: 잔향구는 스타일 선택이므로, 바꿔 보는 데 벌이 있으면 안 된다.

## 9. 반복 파밍 방지 <a id="anti-grind"></a>

| 장치 | 내용 | 막으려는 것 |
|------|------|------------|
| **좁은 수치 폭** | 수치 상승은 T0→T1의 +10%뿐. 잔향구·각인·승화는 수치 없음 | 숫자를 위한 반복 |
| **첫 처치 확정** | 보스 기억·공명석은 첫 처치에 반드시 | 확률 운에 막히는 진행 |
| **결정적 누적** | 재처치 '기억 결' 3개 = 기억 1개. 확률 드랍 없음 | 끝없는 재도전 |
| **필수 반복 0회** | 절편에서 첫 잔향구까지 같은 전투 공간 반복 불필요 ([quests §7](quests.md)) | 강제 반복 |
| **문 변이 (주간)** | 재도전 시 보스방에 변이 1개: ① 되돌이의 저주(같은 콤보 3연속 시 약화) ② 곡소리 장(정지 시 장판) ③ 무거운 안개(회피 거리 −30%, 튕겨내기 창 +2f) ④ 갑주의 밤(일반 적 절반이 갑주귀) ⑤ 장단(박자 분기 피해 +30%) ⑥ 무명의 밤(잔향구 해방기 불가, 기세 충전 2배) | 같은 해법의 반복 |
| **기세 감쇠** | 같은 콤보 경로를 3회 연속 쓰면 그 경로의 기세 충전이 절반 (다른 경로 쓰면 즉시 회복) | 한 가지 콤보 고착 |
| **흉내 보스** | 되돌이 삿갓이 반복을 직접 벌함 | 한 가지 콤보 고착 |
| **동행 공적** | 낯선 사람을 도와도 공명석 교환 화폐를 얻음 | "도와주면 손해" |
| **일일 숙제 없음** | 주간 변이 보상은 누적형 (놓친 주는 다음 주에 이어 받음) | 출석 의무감 |

측정: [concept G6](concept.md#gates), [§10 C4·C5](#combat-gates).

## 10. 전투 플레이테스트 게이트와 텔레메트리 <a id="combat-gates"></a>

모든 기준은 **측정 전 [제안]** 입니다. 결과는 **[측정]** 으로 별도 기록합니다.

| ID | 측정 | 통과 기준 | 방법 |
|----|------|-----------|------|
| C1 | 키 입력 → 공격 애니메이션 첫 프레임 (로컬) | ≤ 50ms | 고속 촬영 또는 내부 계측 — technical 공동 |
| C2 | 적 공격 데이터의 텔레그래프 리드타임 | §3.3 최소치 위반 0건 | 데이터 자동 검사 |
| C3 | 곡비 어멈 소매 공격 튕겨내기 성공률 | 비숙련 ≥ 35%, 숙련 ≥ 65%. 숙련 > 90%면 창 축소 검토 | 텔레메트리 `parry_result{attack_id}` |
| C4 | 절편 후반 15분 사용 콤보 노드 수 | 중앙값 ≥ 7 / 14 | `combo_node_use` |
| C5 | 되돌이 삿갓 처치 전후 콤보 다양도(경로 엔트로피) | ≥ 20% 증가 | `combo_path_entropy` |

## 11. 교차 검토 질문 (technical / art 담당에게)

1. §3.2 프레임 값과 히트스톱을 로컬 연출로 둘 때 서버 판정과의 어긋남 허용 범위.

5. 4인 파티 VFX 불투명도·렌더 우선순위(§5.1)의 구현 비용.
