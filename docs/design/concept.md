## 1. 한 줄 컨셉

> 이름을 잃은 퇴마 길손이 안개(煙霧) 속에서 칼을 쓰는 법(演武)을 되찾으며, 사람들의 이름을 지운 '잔향의 문'을 추적하는 **PC 쿼터뷰(아이소메트릭) 3D 온라인 액션 RPG**. [요구: PC·3D·온라인 액션 RPG] [제안: 쿼터뷰 시점·소재]

제목의 `연무`는 두 뜻을 겹칩니다. 땅을 덮은 안개 **煙霧** 와, 무예를 펼쳐 보이는 **演武**. 안개가 짙을수록 손맛 좋은 무예가 살아남는 수단이 된다는 것이 게임 전체의 정서입니다.

**핵심 약속** ([README](../../README.md)와 동일): *장비 보상을 꺼도 싸우고 싶어지는 전투, 전투 방식을 바꾸는 전설 무기, 낯선 사람을 만나는 온라인 세계.*

## 2. 플레이어 경험 목표 [제안]

- **첫 5분:** 짙은 안개 속에서 깨어나 `약공 → 약공 → 강공` 한 번에 "이 칼은 무겁고 정확하다"는 감각을 받는다.
- **첫 30분:** 박자를 늦추면 다른 기술이 나간다는 것(박자 분기)을 스스로 발견하고, 튕겨내기(패링) 뒤 강공이 따로 있다는 걸 배운다.
- **첫 60~90분:** 낯선 사람 1~3명과 버드역 폐역참에 들어가 보스 `곡비 어멈`을 쓰러뜨리고, 그 잔향으로 **내 패링을 다른 기술로 바꿔 버리는** 첫 전설 장비를 만든다.
- **장기:** 새 전설(잔향구)은 숫자가 아니라 **동작**을 바꾼다. 다음 보스는 그 새 동작을 시험한다.

## 3. 디자인 기둥 [제안]

| # | 기둥 | 근거 요구 | 의미 | 이 기둥이 거부하는 것 |
|---|------|-----------|------|----------------------|
| P1 | **손맛이 먼저** | [요구] 타격감과 사냥 자체의 재미 | 입력 → 반응 → 타격 피드백이 모든 기능보다 우선. 첫 절편에서 무기 1종만 넣는 이유. | 수치만 오르는 자동 전투, 스킬 난사형 전투 |
| P2 | **전설은 동작을 바꾼다** | [요구] 전설 무기·아이템 조합 | 전설 장비(잔향구)는 공격력 대신 콤보 분기·회피·패링 동작을 바꾼다. | 같은 무기의 +1, +2, +3 강화 반복 |
| P3 | **이름을 되찾는 이야기** | [요구] NPC가 큰 이야기 속 미션, 중간보스·보스 | 각 보스는 누군가의 지워진 이름. 처치는 '소탕'이 아니라 '기억'이다. | 맥락 없는 몹 사냥 퀘스트 나열 |
| P4 | **낯선 이와 함께, 그러나 혼자서도** | [요구] 멀티플레이·채팅·낯선 사람 수십 명 | 마을에 20~40명의 낯선 길손, 던전은 1~4인. 혼자서도 완주, 같이 가면 다른 해법. | 강제 파티, 파티 없이는 막히는 메인 진행 |

공통 기반의 협업 원칙([vendor/game-builder/AGENTS.md](../../vendor/game-builder/AGENTS.md): "발견이 새 행동을 열어야 한다", "액션 장르에서 반복적 수치 강화 지양")을 P2·P3에 직접 반영합니다.

## 4. 핵심 루프 [제안]

```text
[초 단위]   입력 → 타격/튕겨내기/회피 → 히트스톱·피드백 → 다음 분기 선택
[분 단위]   교전 → 적 유형이 내 버릇을 벌함 → 다른 분기로 대응 → 잔향 조각 획득
[세션 단위] 마을(등잔포) 의뢰 → 귀로등(포탈)으로 현장 이동 → 필드/던전(1~4인)
            → 보스 처치 → '기억' 획득 → 귀로등으로 귀환 → 막쇠에게 제작 → 새 동작 시험
[장기]      NPC 아크 진행 → 새 지역·새 문 → 새 잔향구 → 새 적이 새 동작을 요구
```

세션 루프의 **귀환 지점(마을)** 이 이 게임의 사회적 공간입니다. 마을에서는 다른 길손의 장비(외형으로 드러나는 잔향구), 명부 게시판에 새겨진 이름, 파티 모집 등불, 채팅을 봅니다.

## 6. 온라인 구조 (디자인 관점)

| 공간 | 인원 | 성격 | 상태 | 상세 |
|------|------|------|------|------|
| 마을 (등잔포) | 채널당 **20~40명 목표** | 비전투. 제작·의뢰·파티 모집·명부 게시판·채팅 | [요구] 수십 명 / [제안] 수치 — 부하 실측 후 조정 | [quests.md §2](quests.md#party-rules) |
| 필드 (억새벌) | 첫 절편: **파티 단위 인스턴스(1~4인)** | 일반 몹 + 중간보스 `되돌이 삿갓` | [제안] | [Q-M04](quests.md#q-m04) |
| 공용 필드 | **후속 12~20명** | 낯선 이와 자연 합류하는 공개 이벤트 | [제안] 첫 절편 이후 | [결정 기록](../production/decision-register.md) |
| 던전 (버드역 폐역참) | **1~4인 인스턴스** | 스토리 보스, 인원수 스케일링, 재접속 규칙 | [요구] 멀티플레이 / [제안] 인원 | [Q-P01](quests.md#q-p01) |
| 스토리 단독 공간 | 1인 | 튜토리얼, 결정적 컷신 | [제안] | [Q-M01](quests.md#q-m01) |

**원칙 [제안]:**

- 메인 진행은 **1인 완주 가능**. 파티는 속도·안전·대체 해법을 준다(예: 곡비 어멈의 '이름 부르기'를 동료가 상여를 쳐서 끊는 해법).
- 마을·필드에서 **채집·처치 경쟁이 생기지 않도록** 채집물은 개인별, 드랍은 개인 귀속.
- 수십 명 동시 보스전(월드보스)은 **보장하지 않는다** — 결정 기록의 범위 경계.
- 네트코드·서버 권한·채널 구조의 구체안은 **technical 담당 소관**. design 요구사항은 [§12 교차 검토 항목](#cross-review)에 모았습니다.

## 7. 성장 구조 — 수평적 성장 [제안] <a id="growth"></a>

- **캐릭터 레벨 없음.** 대신 세 축으로 성장합니다.
  1. **무예(동작) 해금:** NPC 수련 퀘스트로 콤보 분기 노드를 연다. 예: [Q-S02 튕겨내기 수련](quests.md#q-s02) → 패링 후속 분기 2종.
  2. **잔향구(전설) 장착:** 동작 자체를 바꾼다. 출시 시 동시 장착 2개, 첫 절편 1개.
  3. **장인 등급(제작):** 대장장이 강막쇠의 신뢰도에 따라 레시피 단계가 열린다.
- **장비 수치 폭은 좁게:** 등급 간 위력 차이 최대 +10%. 잔향구의 기본 수치는 같은 등급 일반 장비와 동일. 상세: [combat-and-items.md §9](combat-and-items.md#anti-grind)
- 사업 구조 제안(유료 본편 + 외형 + 확장팩, [결정 기록](../production/decision-register.md))과 맞물려, **유료 상품은 외형만** 다룹니다. 확률형 아이템·능력치 판매는 design 범위에서 제안하지 않습니다. [제안]

## 8. 단계별 범위: 전투 검증 → 첫 절편 → 출시 3막 <a id="vertical-slice"></a>

결정 기록의 진행 순서 "10분 전투 검증 → 온라인 수직 절편 → 콘텐츠 확장"을 design 범위로 구체화합니다. 출시 3막 전체는 [narrative.md §7](narrative.md#release-outline).

### 8.0 10분 전투 검증 (오프라인, 절편 이전) [제안]

- 회색 박스 아레나 1개, 환도 콤보 트리 전체, 일반 적 3종(억새 잔향·방패 역졸·그림자 등짐장수), 미니 보스 1종(되돌이 삿갓 축소판).
- 비교 조건: **단순 입력 버전**(약공 연타 + 스킬) vs **분기 콤보 버전**. 보상·UI·이야기 없음.
- 통과해야 첫 절편 제작으로 넘어감: [§10 G0](#gates).

### 8.1 첫 온라인 절편 — 포함 목록 [제안]

| 범주 | 절편 내용 | 수량 |
|------|-----------|------|
| 공간 | 마을 **등잔포**, 필드 **억새벌**(파티 인스턴스), 던전 **버드역 폐역참**, 튜토리얼 안개(1인) | 4 |
| 무기 | **환도** 1종 (콤보 트리 14노드, 기술 4개) | 1 |
| 일반 적 | 억새 잔향, 젖은 손, 방패 역졸, 그림자 등짐장수, 곡소리꾼, 갑주귀 | 6 |
| 중간보스 | **되돌이 삿갓** (내가 반복한 콤보를 흉내 내어 받아침) | 1 |
| 보스 | **곡비 어멈** (3페이즈) | 1 |
| 잔향구(전설) | `곡비의 손목끈`, `되돌이 삿갓` — 둘 다 제작 가능, 1개만 장착 | 2 |
| 제작 | 장인 등급 T0~T3 (T4 승화 제외) | 4단계 |
| 이동 | 등불 웨이포인트 3곳, **귀로등**(마을 귀환 포털) | — |
| 퀘스트 | Q-M01~M05, Q-S01~S05, Q-T01, Q-P01 | 12 |
| NPC | 한설, 강막쇠, 윤가온, 모란(복선 등장), 꼭두 | 5 |
| 온라인 | 마을 채널 20~40 목표, 텍스트 채팅·감정표현, 파티 1~4, 재접속 | — |
| 플레이 시간 목표 | 첫 완주 중앙값 **60~90분** | — |

### 8.2 첫 절편 완료 정의

1. 신규 플레이어가 도움 없이 Q-M01 → Q-M05와 첫 잔향구 제작(Q-S04)까지 도달한다.
2. Q-P01을 1인, 2인, 4인으로 각각 클리어할 수 있다.
3. 던전 진행 중 강제 연결 끊김 후 재접속 규칙([quests.md §2.3](quests.md#reconnect))대로 복귀·진행 보존이 된다.
4. [§10 플레이테스트 게이트](#gates)의 G1~G4, G7이 통과한다. 나머지는 미통과 시 사유와 조치 계획을 기록한다.

## 10. 측정 가능한 플레이테스트 게이트 [제안] <a id="gates"></a>

테스트 인원: 최소 12명(액션 게임 숙련 6 / 비숙련 6). 아래 수치는 **측정 전 목표 기준선**이며 1차 테스트 후 조정합니다. 결과가 나오면 **[측정]** 태그로 별도 기록합니다.

| 게이트 | 단계 | 측정 | 통과 기준 | 측정 방법 |
|--------|------|------|-----------|-----------|
| **G0 보상 없는 재미** | 10분 검증 | 보상·UI 없이 10분 후 "한 판 더" 선택 비율 / 분기 콤보 vs 단순 입력 선호 | ≥ 60% 재플레이 / 분기 버전 선호 ≥ 65% | 세션 종료 선택지 + 설문 |
| **G1 손맛** | 절편 | 설문 "타격감이 좋다" (5점) | 평균 ≥ 4.0, 2점 이하 ≤ 1명 | 종료 설문 |
| **G2 분기 발견** | 절편 | 안내 없이 박자 분기·패링 분기를 처음 쓴 시점 | 중앙값 ≤ 15분, 80% 이상 세션 내 발견 | 텔레메트리 `combo_node_first_use` |
| **G3 전설 체감** | 절편 | 첫 잔향구 장착 후 15분 안에 바뀐 동작 사용 횟수 / 설문 "플레이 방식이 바뀌었다" | 70% 이상이 ≥ 10회 / 평균 ≥ 4.0 | 텔레메트리 + 설문 |
| **G4 보스 공정성** | 절편 | 곡비 어멈전 사망 직후 "무엇에 맞았는지" 맞힌 비율 | ≥ 80% | 테스트 빌드 전용 1문항 팝업 |
| **G5 파티 형성** | 절편 | 파티 등불 모집 시작 → 던전 입장 (4인) | 중앙값 ≤ 2분 | 텔레메트리 |
| **G6 반복 피로** | 절편 | 같은 전투 공간을 3회 이상 반복한 테스터 비율 / "지루한 반복" 설문 | ≤ 20% / 평균 ≤ 2.0 | 텔레메트리 + 설문 |
| **G7 재접속** | 절편 | 던전 중 강제 끊김 → 예약 시간 내 복귀 성공률 / 진행 손실 | ≥ 95% / 0건 | QA 시나리오 20회 |
| **G8 접근성** | 절편 | 보조 옵션을 켠 비숙련 테스터의 완주율 | ≥ 90% | 관찰 + 텔레메트리 |
| **G9 이야기 끌림** | 절편 | "다음 이야기가 궁금하다" (5점) / 한설·막쇠 중 1명 이상 이름 기억 | ≥ 3.8 / ≥ 75% | 설문 |

전투 세부 게이트(입력 반응·텔레그래프 리드타임 등)는 [combat-and-items.md §10](combat-and-items.md#combat-gates). 서버 틱·지연 주입 측정은 technical 문서 소관입니다.

## 12. 교차 검토 항목 (technical 담당에게) <a id="cross-review"></a>

design이 요구하는 값이며, 기술적 가능성·비용 확인이 필요합니다.

1. **입력 버퍼 150ms, 패링 판정창 150ms** — 서버 권한 판정 시 지연 보정 방식. ([combat §3](combat-and-items.md#timing))
2. **히트스톱·카메라 흔들림은 로컬 연출, 피해 판정은 서버** — 4인 파티에서 화면 간 어긋남 허용 범위.
3. **재접속 예약 180초**, 보스전 중 재입장 차단, 목표(objective) 단위 진행 저장. ([quests §2.3](quests.md#reconnect))
4. **마을 채널 상한 40 / 병합 하한 20.**
5. **개인 드랍 / 개인 채집 노드**, 제작 재료 귀속, 중복 지급 방지(결정 기록의 경제 신뢰성 증거와 연결).
6. 텔레메트리 이벤트 목록(§10, combat §10)의 수집 가능 여부.
7. 잔향구가 바꾸는 동작은 **데이터(분기 노드 교체)로 정의**하려 함 — 애니메이션 클립 수 예산과 함께 art 문서와 확인 필요. ([combat §7](combat-and-items.md#legendaries))
