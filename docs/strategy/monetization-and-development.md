# 수익화 & 개발 전략

> 작성일: 2026-11-08 · 상태: 방향 검토 (최종 결정 전)
> 전제: 1인 개발 · 게임 전문지식 없음 · 코드/에셋/사운드 전부 AI·에이전트로 제작 · 게임당 토큰/도구 예산 **100만 원 이하** (실제로는 그보다 적게)

## 1. 핵심 결론

1. **3D 디아블로류는 첫 수익화 작품으로 부적합.** 예산 안에 완성 가능성이 낮고, AI가 가장 약한 영역(리깅·애니메이션·타격감)에 의존한다.
2. **이미 서비스 중인 «펭귄미식회: 북극 3스타»를 출시 수준으로 끌어올리는 것이 가장 싸고 빠른 길.** 새로 시작하면 지금까지의 투자(PR 25개+)를 버리게 된다.
3. **출시 채널은 웹게임 포털 → 앱인토스 → 구글 플레이 순.** 등록비 없이 반응을 먼저 확인한다.
4. 인디 게임 대부분은 출시 후 수십만 원 이하를 번다. **작게 출시 → 반응 확인 → 확장**이 원칙.

| | 3D 디아블로 (PC) | 2D 쿼터뷰 파밍 RPG | 메이플식 2D 횡스크롤 | 간단 모바일 (디펜스/퍼즐) | **펭귄미식회 (진행 중)** |

**나중에 디아블로 감성을 원하면:** 3D 대신 "2D 쿼터뷰 + 아이템 파밍(일반→희귀→전설) + 성장"으로 축소하는 것이 현실적인 절충안이다 (YEONMU 방향 전환 후보).

## 3. 펭귄미식회 — 다음 단계

현재: https://penguin-gourmet-club.vercel.app 서비스 중. 사냥, 식당 운영, 뽑기(전설 무기), 밤 습격 디펜스, 별점 심사, 사운드, 광고 연결 틀(noop provider) 구현 완료. 오버홀 계획(`overhaul-2026-10.plan.md`, 게임 저장소) 0~1단계 완료.

**권장 순서**
1. 오버홀 2단계~ : 사냥감 등급 = 요리 등급 → 가격 공식/업그레이드 정리 → 별점 심사(주문 카드·도장·피날레) → 2막(사막)
2. 구글 로그인 + 게스트 + 클라우드 저장 (Supabase, 계정 스켈레톤은 fake provider로 이미 존재)
3. 랭킹 + 별점 인증서 공유 + 친구 추천 코드
4. 보상형 광고 실제 연결 (웹: H5 Games Ads / 앱: AdMob)
5. **길드는 사용자가 모인 뒤에.** 서버·계정·채팅·신고 기능이 따라와 비용과 작업량이 급증한다.

## 4. 출시 & 수익화 로드맵

1. **웹게임 포털 (Poki / CrazyGames)** — 등록비 없음, 광고 수익 배분. 웹게임이라 바로 맞음. *각 포털 SDK·심사 조건은 별도 조사 필요.*
2. **앱인토스 (토스 미니앱)** — 한국 유저 접근성.
3. **itch.io** — 무료, 반응 테스트용.
4. 반응 좋으면 **Google Play** (Capacitor 등으로 패키징) → 이후 App Store / Steam 검토.

**수익 모델:** 보상형 광고(이어하기·보너스) + 뽑기 재화 소액결제 + 광고 제거 패스. 광고 제거 패스는 결제와 계정이 필요하므로 계정 도입 후 결정.

## 6. 개발 프로세스 (리스크 최소화)

1. 1~2주: 웹에서 핵심 재미만 프로토타입 (예: 사냥 → 드랍 → 장착 → 강해짐)
2. 직접 플레이 + 지인 테스트. 재미없으면 여기서 중단 (손실 최소)
3. 재미있으면 에셋 다듬기 + 광고/결제 → 출시
4. 반응 좋으면 플랫폼 확장
