# 사전 검증

## 1단계: 검증 명령 실행

> **TODO**: 스택 확정 후 아래를 실제 명령으로 교체할 것.
> 가이드: `docs/stack-guide.md`

```bash
# <pm> run lint
# <pm> run build
# <pm> run test
```

스택이 아직 미정이면 `package.json`의 `scripts`를 읽어 존재하는 것만 실행한다.
`package.json`이 없으면 "검증할 대상 없음"을 알리고 종료한다.

## 2단계: 실패 처리

- 실패한 명령의 **출력 원문**을 보여준다
- 원인을 진단하고 고친다
- 고친 뒤 실패한 명령을 **다시 실행**해 통과를 확인한다

## 3단계: 결과 보고

| 검사 | 결과 |
|------|------|
| lint | ✅ / ❌ / ⏭️ 없음 |
| build | ✅ / ❌ / ⏭️ 없음 |
| test | ✅ / ❌ / ⏭️ 없음 |

## 금지

- ❌ 통과시키려고 테스트를 `skip`하거나 단언을 지우지 않는다
- ❌ 린트 오류를 `eslint-disable`로 덮지 않는다 (근본 수정)
- ❌ 실패를 "통과"로 보고하지 않는다
