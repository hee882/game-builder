# game-builder

세 가지 게임의 조작감과 성장 연출을 비교하는 **플레이룸**입니다.

## 현황

TypeScript + Phaser 3 + Vite로 구현한 브라우저용 프로토타입입니다.

- **작은 성채**: 타워 3종, 강화, 광역 공격·둔화, 5웨이브 방어
- **유물 사냥꾼**: 클릭·드래그 / WASD 이동, 자동 공격, 보석 수집, 능력 선택, 보스
- **골목상회**: 손님 응대, 직원 자동화, 가게 업그레이드, 4층 증축, 홍보

상단에서 게임을 전환하거나 **성장한 모습 보기**로 후반 모습을 비교합니다. 각 게임 진행은 페이지를 열어둔 동안 유지됩니다. 평가·메모만 브라우저에 저장되며 JSON으로 내려받을 수 있습니다. 처음부터 버튼은 선택한 게임만 초기화합니다.

## 실행

Node.js 22.18 이상 또는 24 권장 (테스트는 Node의 TypeScript 직접 실행 사용).

```sh
npm ci
npm run dev
```

`http://127.0.0.1:5197`을 브라우저에서 엽니다. 다른 프로젝트의 개발 서버와 혼동하지 않도록 5197 포트를 고정합니다. 같은 Wi-Fi의 휴대폰은 터미널에 표시된 Network 주소로 접속할 수 있습니다. 방화벽 설정에 따라 접근이 제한될 수 있습니다.

```sh
npm run check
npm test
npm run build
```

## 샘플의 범위

그래픽은 코드로 그린 2D 일러스트이며 효과음은 Web Audio로 합성합니다. 외부 이미지 자산, 광고, 결제, 서버, 계정은 사용하지 않습니다. Google Fonts가 차단되면 시스템 글꼴로 표시됩니다. 게임 상태는 새로고침하면 초기화됩니다.

이 샘플은 재미와 시각적 방향을 비교하기 위한 것이며, 출시용 콘텐츠 분량·경제 밸런스·모바일 성능 검증은 별도입니다. 현재 게임 장면은 매 프레임 Canvas에 그린 뒤 Phaser 텍스처에 반영합니다. 대규모 객체가 필요한 출시 버전에서는 개별 스프라이트·배칭으로 옮겨 최적화할 수 있습니다.

## 구조

```
src/
  game-state.ts  # 시뮬레이션, 경제, 전투
  renderer.ts    # 월드·캐릭터·효과 렌더링
  main.ts        # Phaser 루프, 입력, 쇼룸 UI
  style.css      # 반응형 레이아웃
tests/
  game-state.test.mjs
```
